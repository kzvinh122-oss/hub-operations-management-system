# Hub Operations Management System

A simulated logistics hub operations management project covering inbound, sorting, cross-docking and outbound processes.

## 📌 Project Overview

This project simulates the operational flow of a logistics hub and analyzes shipment data to support warehouse performance monitoring.

The project focuses on:

- Inbound operations
- Shipment scanning
- Sorting operations
- Cross-docking
- Outbound operations
- Shipment error analysis
- Processing time analysis
- Operational KPI monitoring
